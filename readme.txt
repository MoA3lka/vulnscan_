    VULNSCAN
Web-Based Vulnerability Scanner

Project Overview
This project is a web-based vulnerability scanning system developed using the Django framework and Python. The system allows users to input an IP address and perform a network scan to detect open ports and potential security risks. Based on the detected ports, the system automatically classifies the risk level of the scanned device as Low, Medium, or High.

The aim of this project is to demonstrate the application of software engineering principles such as requirements analysis, system design, implementation, and testing while also introducing basic cybersecurity concepts related to vulnerability detection.

This project was developed as part of a Level 5 Software Development assignment.

Key Features:
IP address input and validation
Network port scanning functionality
Automatic risk classification (Low, Medium, High)
Detection of exposed services through open ports
Storage of scan results in a database
Display of current and previous scan results
Alert generation for high-risk results
Web-based user interface
Automated testing using Django's testing framework

Technologies Used
The system was built using the following technologies:
Python – Core programming language
Django – Web application framework
HTML – Front-end structure
CSS – User interface styling
SQLite – Database for storing scan results
Python Socket Library – Used for port scanning functionality
Git & GitHub – Version control and project repository
